# Playwright Test Setup — README

_This guide walks through installing dependencies and running the Playwright test suite._

## Prerequisites

- Install Node.js
- Install npm
- Install Playwright by running the following command:

```bash
npm init playwright@latest
```

## Steps to Run the Tests

1. Open the file named **"AA OPEN THIS FIRST.js"** and update its values as needed.
2. Run the following command to open the Playwright UI:

   ```bash
   npx playwright test --ui
   ```

3. Click **"Play All"** or press **F5** to run all the tests.
4. Once all the tests run successfully, open the **playwright-report** folder and navigate to **index.html**.
5. Copy the path of `index.html` and open it in your browser.

**Test done.** You have successfully set up and run the Playwright test suite.
